# Infinity Code OP Harness — Revision 3.0 (Repo-Grounded) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Turn Infinity Code into a premium, fast, cost-safe harness by wrapping the existing provider/context/learning infrastructure and adding the genuinely-new personality, onboarding, and design layers.

**Architecture:** The repo already has: DeepSeek V4 routed as the default cheap/coder model (via OpenRouter), a content-provider manager (`core/providers.py`), a budget config block, a code-context engine (`core/repo_context.py`), and a learning/retrain loop. This revision therefore *wraps and extends* those rather than building duplicates. The only fully net-new systems are the frontend personality service, the onboarding tour, and design-token polish.

**Tech Stack:** Python (FastAPI-style backend) + React/TypeScript + Tailwind + Tauri. Existing patterns to follow: `src/lib/appearance.ts` (localSettings store), `backend/core/router.py` (model council), `backend/core/repo_context.py` (context engine), `backend/core/sandbox.py` (execution sandbox).
